Case study

Ultrasonic crack detection run validation

Client
Onshore liquid pipeline operator
Region
South America
Services
  • ILI services

We have completed various integrity management scopes for onshore liquid pipeline operators within South America. This case study focuses on reviewing an ultrasonic crack detection ILI tool performance in line with API 1163 for three pipeline segments of a liquid pipeline.

The project goal was to help the operator evaluate tool performance reviewing detection, identification and sizing of any reported planar indications and compare to the vendor’s stated performance specification.

01

Project stats

Number of pipeline segments
3
Number of joints excavated
73

02

Background

The operator contracted an inspection vendor to complete an in-line inspection along their >500 km liquid pipeline system which comprised of three segments. Following the inspections, the operator executed an extensive field verification campaign.

03

The approach

We reviewed the performance of the ultrasonic crack detection ILI tool in-line with the guidance outlined in API 1163 (In-Line Inspection Systems Qualification). This standard is performance-based and provides requirements for the qualification processes of an in-line inspection run. The objective was to compare the field data with the ILI vendor’s stated performance specification for the detection, identification and sizing of planar anomalies.

Considering the extensive field data collected by the client, we were able to evaluate the following per pipeline segment:

  • Probability of Detection (POD)
  • Probability of Identification (POI)
  • Probability of Sizing (POS)

In addition, we were also able to review tool performance in discrete portions of each pipeline, where there was a variation in pipe geometry, manufacturer, weld type and wall thickness.

04

Results

  • The results of the work provided the operator with an understanding of tool performance along the entire length of their pipeline system to support their ongoing integrity management program.
